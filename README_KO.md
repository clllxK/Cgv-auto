# 용아맥 오디세이 알리미 — 폰 단독 실행 버전

목표:
- CGV 용산아이파크몰
- 영화 `오디세이`
- `IMAX` 새 날짜가 열리는지 확인
- 기본 30초 간격
- 새 날짜 발견 시 **안드로이드 폰 알림**
- 카카오톡 **나와의 채팅**으로도 알림
- PC/서버 없이 휴대폰에서 계속 실행

> 자동 예매나 좌석 선점 기능은 없습니다. 새 편성을 감지해 알리는 도구입니다.

## 왜 포그라운드 서비스인가

30초~2분 단위로 화면이 꺼진 상태에서도 지속적으로 확인하려면 일반 예약 작업(WorkManager)만으로는 어렵습니다.
이 앱은 사용자가 직접 켜고 끄는 `specialUse` 포그라운드 서비스를 사용하고, 실행 중에는
알림창에 `용아맥 오디세이 감시 중` 고정 알림이 표시됩니다.

30초 모드는 배터리를 더 사용합니다. 용아맥 새 날짜를 기다리는 동안만 켜는 것을 권장합니다.

# 카카오 설정 — 폰 브라우저에서 한 번만

카카오톡 나와의 채팅 전송은 카카오 공식 REST API를 사용합니다.

1. Kakao Developers에서 앱 생성
2. `카카오 로그인` → 사용 설정 ON
3. `앱 → 플랫폼 키 → REST API 키` 확인
4. REST API 키의 Redirect URI에 정확히 등록:
   `http://localhost:8765/callback`
5. 같은 REST API 키의 `Client Secret` 확인
6. `카카오 로그인 → 동의항목`에서 카카오톡 메시지 전송(`talk_message`) 사용
7. `제품 링크 관리 → 웹 도메인`에:
   `https://cgv.co.kr`
8. 앱을 열고 REST API 키와 Client Secret 입력 → **키 저장**
9. **카카오 로그인** 누르고 브라우저에서 동의
10. **카카오톡 테스트 보내기**로 확인

키/토큰은 Android Keystore의 AES/GCM 키를 사용해 기기 내부 암호화 저장합니다.

# 설치 가능한 APK 만들기

이 압축은 완성된 Android 프로젝트입니다.

## 방법 A — GitHub Actions로 1회 빌드
런타임은 GitHub를 전혀 사용하지 않습니다. **APK를 만드는 순간에만** 사용합니다.

1. GitHub에서 Private repository 생성
2. 이 프로젝트 파일을 repository에 업로드
3. Actions 탭 → `Build Android APK`
4. `Run workflow`
5. 완료 후 Artifacts의 `yongsan-imax-odyssey-watcher-apk` 다운로드
6. 압축 안의 `app-debug.apk`를 갤럭시에 설치

## 방법 B — Android Studio / AndroidIDE
프로젝트 폴더를 열고 `app`의 debug APK를 빌드하면 됩니다.

빌드 기준:
- JDK 17
- Gradle 9.5
- Android Gradle Plugin 9.3.0
- compileSdk/targetSdk 36

# 설치 후 권장 설정 — 갤럭시

앱 안에서 `배터리 최적화 제외 설정` 버튼을 눌러 제외합니다.

추가로 삼성 설정에서:
`설정 → 배터리 → 백그라운드 사용 제한` 쪽에서 이 앱을 절전 앱에 넣지 말고,
가능하면 앱 배터리 사용을 `제한 없음`으로 설정하세요.

30초 감시는 CPU가 잠들지 않도록 부분 WakeLock을 유지하므로 평소 앱보다 배터리 사용량이 높습니다.

# 감지 방식

첫 시작:
1. 오늘부터 약 17일 범위의 CGV 용산 시간표를 조회
2. 현재 이미 열려 있는 마지막 `오디세이 + IMAX` 날짜를 기준값으로 저장
3. **기존 일정은 알리지 않음**

이후:
- 기준 날짜 뒤의 날짜를 순환 확인
- `+1일`을 가장 자주 확인
- 새 IMAX 날짜가 발견되면 즉시 알림
- 발견한 날짜를 새 기준으로 저장
- 같은 날짜 중복 알림 방지

CGV 조회가 일시적으로 403/429 또는 네트워크 오류가 나면 감시는 종료하지 않고 자동 재시도합니다.
연속 실패가 일정 횟수에 도달하면 폰에 오류 알림도 보냅니다.

# 주의

CGV 웹사이트/API 구조가 바뀌면 감지 코드(`CgvClient.java`) 수정이 필요할 수 있습니다.
이 프로젝트는 현재 확인 가능한 CGV 예매 페이지 구조를 바탕으로 작성했으며, 실제 첫 실행에서 조회가 정상인지 확인하도록 되어 있습니다. CGV가 내부 구조나 차단 정책을 바꾸면 감지 코드 수정이 필요할 수 있습니다.

카카오 API 설정 또는 정책이 변경되면 Kakao Developers 설정을 다시 확인해야 할 수 있습니다.
